> **定性（必读）**

> 本文与 `treatment.md`（定位/结构）、`口播稿.md`（字幕文本）、`上屏文字出处表.md`（逐条出处）、`渲染命令与验收.md`（命令与验收）配套使用。

## 0. 分拍要求（本片的节奏宪法）

依据 `references/product-demo-continuity.md:26-30`：

> 把一次观看分成「**移动到焦点 → 落定 → 读懂/状态变化**」，**移动时长和阅读时长分别调**；整体减速会同时拖慢接镜，整体加速会吞掉阅读。

本单每个镜头都拆成三拍，且遵守：

| 拍 | 作用 | 本片建议时长 | 实现 |
|---|---|---|---|
| ① 移动到焦点 | 平面缩放/平移到本镜主要阅读区 | 0.3–0.8 s（试起值，按目标屏幕调） | GSAP `fromTo` 只动 `x / y / scale`，**不动 `left/top/width`**（`SKILL.md:40` 规定 check 拒绝 layout motion） |
| ② 落定 | 停止运动、元素稳定 | 0.2–0.3 s | 缓出 `--ease-out`（`tokens.css:34`），不弹跳 |
| ③ 读懂/状态变化 | 文字逐项出现 / 状态更新 / 停留读图 | ≥1.0 s，长句 ≥2.0 s | 稳定段靠「内容增长」推进，不靠相机游走（`product-demo-continuity.md:28,35`） |

**三条硬纪律**
1. **不得剪成「点击即完成」**：当前无真实操作录屏，所有镜头只允许「全貌 → 取景 → 停住读字」；任何「点击/输入/提交 → 结果」镜头一律标 `待录屏`，不得用动画伪造（`craft.md:9`、`product-demo-continuity.md:30,48`）。
2. **保留身份锚点**：导航栏 wordmark `星厨传承`、状态栏 `星厨传承 · EDITION 01`、纸底 `#EDE8DB`、朱红 `#B8321A` 强调在换页时保持可辨认（`product-demo-continuity.md:36`）。
3. **接缝只写一句交接**：`上一镜焦点 → 下一镜落点 → 新信息`，见第 4 节接缝表（`product-demo-continuity.md:42`）。

**接缝记录格式**（`product-demo-continuity.md:58`，补齐录屏后逐段填）：
`事件｜当前阅读区｜保留的身份锚点｜起止构图｜内容动作/取景动作｜落定时刻｜读取窗口｜下镜新增信息`

取景规则（`product-demo-continuity.md:32-38,44-48`）：
- 全貌镜认载体与关系，近景镜读关键文字；一次只指定一个主要阅读区。
- 超长截图（1904×8916 等）用包装层平面缩放/平移，**对象位置与取景缩放分别调**，避免换行把比例拉坏；包装层初态明确设置，`fromTo` 用 `immediateRender:false` 防未来近景提前出现在首帧（`:52`）。
- 裁切前后能定位同一焦点且关键文字完整才算聚焦；**不允许把文字抹掉再编写不存在的反馈**（`:48`）。
- 字幕占位与边距先减掉再定外框；中文字号按最终 1920×1080 检查，不照抄参考英文行长（`:25,38`）。

## 5. 声音/节奏落点清单（无旁白方案）

- BGM：优先 `references/scores/first-light.abc`（或 `four-rooms.abc` / `signal.abc`）经 `om sound` 生成；或 `OM.music({ bpm })` + `OM.beat(n)`（`SKILL.md:47,49`）。
- 落点 `OM.sfx('hit', t)` 命中时刻（方案 A）：`0.6 / 6.7 / 14.8 / 24.5 / 30.6 / 37.5 / 43.6 / 50.5 / 57.4 / 62.6 + 4 个数值落点 / 74.6`，约每 30 s 8–15 个（`SKILL.md:49`）。
- 有意静音/仅 BGM 时用 `om render --silent` 显式声明；走 BGM 则先 `om sound`，渲完看频谱（`SKILL.md:49`）。
- **无旁白不制造听觉留白**：稳定段用文字逐项出现/状态更新推进，不靠放慢画面补气口（`product-demo-continuity.md:35`）。
