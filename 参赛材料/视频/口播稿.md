## 2. Windows 中文口播限制（为什么用 none）

| 选项 | 结论 | 依据 |
|---|---|---|
| `om voice --voice say:Tingting` | **不可用**：`say:` 是 macOS 专属系统 TTS，本环境为 Windows 11，`om --help` 列出的该 voice 在本机无对应引擎 | `om --help` 中 `[--voice say:Tingting\|zf_xiaobei]`；`say` 前缀为 macOS |
| 中文经 Kokoro / espeak | **不建议**：中文经 espeak 输出**无声调**，正式片不可用 | 任务给定限制，本轮沿用（未实测生成音频） |
| 英文系统音读中文稿 | 与全中文界面/字幕不协调，弃用 | — |
| **自备真人录音 `--audio`** | **唯一推荐的中文口播路径** | `SKILL.md:25`：`or --audio <your recording>` |

> 结论：本片默认 `none`。这不降低交付质量——`SKILL.md:44` 明确 none 是口播未定时的默认项；视频信息由字幕与真实界面文字承担。

## 3. 自备录音替代路径（将来若要中文口播）

1. **录什么**：朗读第 4 节 S01–S12 的字幕文本，**原样、不加不减、不改数字**（`product-demo-continuity.md:35`：不能自动增删原话）。
2. **怎么录**：单声道、44.1 kHz 或 48 kHz、wav/m4a，安静环境，一句一停；按分镜号命名，如 `音频/S01.wav`。
3. **命令**：
   - `om voice <dir> --audio <file> --fit`（`--fit` 让词轴贴合时间轴；`om --help` 列有 `--fit`）
   - 或先写 `script.txt` 用 `om voice <dir> --text script.txt` 生成词轴 `OM.cue` 与 `out/*.srt`（`SKILL.md:25`）
4. **产物**：`out/*.srt` 字幕；`om render` 前确认音轨与字幕同步；`om sound` 让 BGM 在语音下 ducking（`SKILL.md:49`）。
5. **无音轨告警**：若最终仍决定无旁白且无 BGM，`om render --silent` 显式声明有意静音；有 BGM 则不要加 `--silent`。
6. **留白**：口播没有气口时，靠放慢画面**无法**创造听觉留白；稳定段用文字逐项出现推进（`product-demo-continuity.md:35`）。

## 5. 字幕呈现规范

| 项 | 规则 |
|---|---|
| 字体 | 中文 `Noto Sans SC`（bundled，`om fonts add`）；拉丁/数字按站点 `JetBrains Mono`（`tokens.css:24`）作标签 |
| 颜色 | 正文 `#12100E`（`--ink`）配纸底 `#EDE8DB`；强调 `#B8321A`（`--vermillion`）—— 均取 `tokens.css:8,11,14` 真实值 |
| 对比度 | 按 `om check` 检查低对比文字；纸纹/颗粒层放在内容层之下（`SKILL.md:40`），避免全屏装饰层盖住字幕 |
| 读图时间 | 每条字幕「读懂」拍 ≥1.0 s，长句 ≥2.0 s（`分镜节奏单.md` 第 0 节） |
| 换行 | 按 1920×1080 实际画幅检查中文换行，不照抄参考片英文行长（`product-demo-continuity.md:38`） |
| 稳定段推进 | 画面停住时靠文字逐项出现/状态更新推进，不靠相机游走（`product-demo-continuity.md:28,35`） |
| 无旁白留白 | 不靠放慢画面制造听觉留白；留白是「停住读字」，不是空白帧（`om check` 会查空白结尾） |
