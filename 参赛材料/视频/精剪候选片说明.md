## 七、渲染实现要点（可复现）

每段滤镜链：`scale=1920:-2` → `crop=1920:1080:0:'min(ih-oh,1200*t/DUR)'` → 底条 → 逐行 `drawtext` → `fade in 0.3s`（末段加 `fade out 0.8s`）→ `fps=30,format=yuv420p`；12 段 `-c copy` concat。

**两个 ffmpeg 表达式坑（实测）**：
- `drawbox` 的 `y` 若写 `h-215`，`h` 会被自身高度参数遮蔽（算成 `215-215=0`），底条会跑到画面顶部 → 必须写 `y=ih-215`。
- `drawtext` 的 `y` **不认 `ih`**（报 `Undefined constant`），只认 `h` → 必须写 `y=h-170+j*46`。
- Python `subprocess` 不继承 Bash 里 export 的 PATH，须用绝对路径 `C:\Tools\ffmpeg\bin\ffmpeg.exe`（默认 PATH 命中 2013 版旧 ffmpeg，不支持 `-hide_banner`）。
