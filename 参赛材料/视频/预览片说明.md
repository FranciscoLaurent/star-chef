# 真实素材预览片说明（非提交件）

> 生成日：2026-11-06　|　文件：`星厨传承_真实素材预览_非提交件.mp4`

## 一、这是什么

由 `web/screenshots/` 中 **8 张真实界面截图**直接合成的一条 **19.7 秒** 素材预览片。

- 用途：仅供团队内部查看「真实 UI 放进视频里是什么效果」，**不是**《作品展示介绍视频》成片。
- 定性：3–5 分钟 MP4 属**团队自定的可选演示/发布视频规格（P3）**，绝非本届必交件；第二十届区域赛初赛**唯一必交件是《项目计划书》**。
- 真实性：画面 **100% 来自真实截图**，未新增任何文字、数字、界面或转场；无旁白、无 BGM、无字幕、无动效包装。
- 长图处理：多数截图为超长整页图（如 1904×8916），采用「等比缩放到宽 1920 → 裁 1920×1080 → 2.5 秒内缓慢下移最多 700px」展示顶部核心区域，**未覆盖整页**。

## 四、已知瑕疵（正式成片必须处理，本片未处理）

1. **开发期标记残留**：部分截图带截图工具标签（如 `#3 Snapshot`）与浏览器/扩展痕迹，不得上正式片。
2. **真实人物信息**：画面含真实厨师肖像、姓名与公开履历文字、外部来源链接（`www.cyxh.org/...`）。属真实业务数据，但**对外发布前须按 `上屏文字出处表.md` 逐条核验**，并确认肖像与来源引用合规。
3. **页面原有宣传文案**：如首页「让两千万厨师的手艺被看见」，是截图内既有文字、非本片新增；正式片若上屏同样需要可核实出处。
4. **无状态变化**：纯静态截图轮播，不满足 `product-demo-continuity.md` 的「移动到焦点 → 落定 → 读懂/状态变化」三拍要求，**不能暗示任何交互能力**。
5. **无润色**：无转场、无节奏设计、无片头片尾、无版权行、无匿名复核记录。

## 五、与 3–5 分钟成片的差距

本片**不是**成片，也不替代任何验收。要产出符合质量门槛的成片，前置条件见：

- `素材核验清单.md` §3.2 的 **R1–R8 真实操作录屏**（6 路由 + 搜索跳转 + 状态栏数值；SDR / 1920×1080 / 30fps / 连续因果，保留「处理中」等待与身份锚点）
- 中文口播**自备真人录音**，或团队书面确认「无旁白 + BGM」
- 团队对方案 A/B、6 路由顺序、版权行是否上屏的书面确认
- 渲染前 PATH 前置 `/c/Tools/ffmpeg/bin`
- 独立审片人 + 最终 MP4 SHA-256 绑定；逐条过 `渲染命令与验收.md` 的 **A1–A8**（含 `om check` 0 errors、`om qa`、`om still` 四帧、上屏文字出处表、匿名检查）

> 务实建议：3–5 分钟属 Tutorial/Explainer 长片；标准 Launch film 为 30–90 s。若目标是初赛加分而非完整教程，建议优先做 60–90 s 精剪版，见 `treatment.md` 与 `分镜节奏单.md`（11 镜 / 86 s）。

## 六、复现命令（逐段生成后 concat）

```bash
export PATH="/c/Tools/ffmpeg/bin:$PATH"
DUR=2.5
# 每段（i = 01..08，输入为对应真实截图）
ffmpeg -y -loop 1 -framerate 30 -t $DUR -i ${i}.png \
  -vf "scale=1920:-2,crop=1920:1080:0:'min(ih-oh,700*t/${DUR})',setsar=1,fps=30,format=yuv420p" \
  -c:v libx264 -preset veryfast -crf 20 -r 30 -an -pix_fmt yuv420p seg${i}.mp4
# 拼接（list.txt 每行 file 'segNN.mp4'）
ffmpeg -y -f concat -safe 0 -i list.txt -c copy -movflags +faststart preview.mp4
```
